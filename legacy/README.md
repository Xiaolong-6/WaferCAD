# Legacy implementation

This directory archives the implementation that predates the current static vector WaferCAD application.

It is retained only as historical and implementation reference. Nothing under this directory is deployed by GitHub Pages or imported by the active application.

Archived material includes:

- FastAPI/gdstk backend code;
- the previous static client;
- Python dependencies;
- Playwright/package tooling;
- previous tests and fixtures;
- previous documentation and handoff notes;
- old helper tools.

New work should target `site/` and `docs/`.
