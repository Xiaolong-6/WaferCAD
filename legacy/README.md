# Legacy implementation

This directory contains selected source and verification material from the pre-rewrite WaferCAD implementation.

It is historical reference only:

- nothing under `legacy/` is deployed;
- nothing under `legacy/` is imported by the active browser application;
- legacy package, Python, Playwright, and test files are not part of the current development toolchain;
- stale handoff/agent instruction documents have been removed so they cannot be mistaken for current guidance;
- duplicate third-party bundles are not retained here.

Current development guidance lives in `README.md` and `docs/`. The active application lives in `site/`.
