# M1.5 font comparison asset

Inter Variable is an unmodified, locally hosted review candidate, not the selected product font.
Source: https://github.com/rsms/inter/tree/master/docs/font-files
License: SIL Open Font License 1.1, distributed alongside the binary as `LICENSE.txt`.
The checkpoint records the pinned upstream revision, byte count and SHA-256.
Inter supplies Latin/Greek UI text; Chinese remains in the system fallback stack.
No runtime CDN request is used. The accepted M1 system font tokens are unchanged.
