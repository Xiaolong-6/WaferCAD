Workflow

How WaferCAD works

The process sequence is the central object: each applied or recorded step advances the same editable geometric structure.

01

Import or draw

Load GDSII / OASIS, browse cells and layers, or draw a process mask directly.

02

Build the process

Deposit, extend, etch, implant, define electrical regions, and record non-geometric steps.

03

Inspect each state

Main, Mask, 3D, and Section consume the same current process state and stay synchronized.

04

Explore alternatives

Restore process states, bookmark inspection milestones, or branch an alternative Variant.

Vector 2.5D keeps process geometry lightweight and editable. Workspace controls explain terms such as Extend, Front / Back, Variants, and Recovery where they first appear.

Scope

Built for structural reasoning

WaferCAD focuses on evolving fabrication geometry and explicit structural annotations, without presenting visual approximations as calibrated process or device physics.

Designed for

Process development Literature reconstruction Device design Teaching Technical communication

Model boundary

Geometric process model. No calibrated plasma, chemistry, diffusion, or activation solver.

Structural annotations. Implant and electrical regions do not solve electrostatics or carrier transport.

Layout is an input. WaferCAD is not a replacement for a full IC layout editor.

Browser-only · no installation required Literature reconstructions include source publications and DOI links.
