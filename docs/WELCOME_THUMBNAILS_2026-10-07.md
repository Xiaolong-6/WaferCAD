# Welcome thumbnails on demand - 2026-10-07

Branch: `codex/project-io-geometry-sharing`; baseline `42f2468`. Feature pushes use `[skip ci]` with no CI, main merge or deployment.

The Welcome page now initially displays five small WebP images generated by the real application 3D renderer from each final-only example. The saved camera orientation, ROI, Z-collapse and physical model determine the image. No generative image changes, geometry simplification or model edits are involved. Default selected view is 3D to match the image. Each image is 640 by 560 pixels at quality 0.86; the five images total 45,670 bytes, compared with the previous 1,081,782-byte final-only project payload (95.8% smaller initial image payload).

Browsing or scrolling does not start an app iframe or fetch any `.wafercad` project. The user can click the image/Explore 3D button, activate it with Enter, or choose a Main/Mask/3D/Section tab. That starts only the requested card and loads its existing final-only preview once. Switching tabs reuses the loaded project. The thumbnail remains visible during loading and after a load failure; a missing image falls back to the live renderer. Other cards remain idle. Open example bypasses preview loading and opens the unchanged complete original with History and Variants.

Project/layout parsing modules are now imported only when the user selects a file to import. Their existing size limits and staged-file behavior remain authoritative. They are no longer part of Welcome's initial dependency graph.
