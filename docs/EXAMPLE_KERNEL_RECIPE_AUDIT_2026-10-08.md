## Scope and observations

All five Welcome production examples must ship as self-contained `.wafercad`
projects, have an exportable File or Draw Mask, preserve the full process
sequence for every editable Variant, and reconstruct from the recorded Base
using **Process → Recipe → Run All → Rebuild Base**. A remembered History
snapshot, successful import or final 3D preview alone is insufficient evidence
of reproducibility.

examples.

## Changes on repair branch

- Store a validated, portable `processRecipe.base` for every Variant,
  History node and Snapshot. The Base includes original shape, dimensions,
  substrate material and color, and optional canonical wafer-array tiling.
- `Run All` preflight uses the *new* Base material. Base reset recreates
  original Si/Ge substrate or the 25 × 25 site array while respecting the
  user's existing **Clear history** versus **Keep history as Variant** choice.
- Backfill complete editable Recipes from legacy process ancestry, keeping
  captured File/Draw mask Cell/Layer, transform and ROI, material, thickness,
  etch/deposition mode, implants and electrical annotations.
- Recover missing legacy pyramid `seed`, `featureCv` and `heightCv` from
  recorded Kernel surface metadata. Keep regeneration synchronized through
  `scripts/maintenance/backfill-example-recipes.mjs` and the existing
  photodetector Kernel generator.
- Add automated all-example/Variant Recipe and Base assertions
  (`site/tests/example-recipe-audit.test.mjs`), actual GDSII/OASIS export
  round-trips (`site/tests/example-mask-export.test.mjs`), and Chromium
  **Run All** acceptance with real project export and structural comparison
  (`scripts/example-recipe-runall-acceptance.mjs`).

## Strict provenance / known remaining work

Legacy PERC/Tandem/Microdisk History is reconstructed from historical
Kernel-model snapshots. The migration adds explicit executable Recipe input;
it does **not** retroactively prove every old snapshot was generated by the
current Kernel. The native JLFET single-site reference and photodetector have
separate replay reconstruction harnesses. Strict acceptance must verify that
every production project and published Variant has been freshly replayed
through the current Kernel, with scientific final-geometry equivalence,
**before replacing canonical assets or merging to main**.

A 625-site array cannot be reduced to a one-device test: its full-array
`Run All` needs to pass and the exported result must still be a canonical
wafer-array model. Do not accept a preview or single-site-only success as a
substitute.
