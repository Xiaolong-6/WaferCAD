# UI v2 cross-view synchronization audit — 2026-10-11

Scope: **read-only static analysis** of `site/app.js`, `site/controllers/*`, `site/selection-geometry.js`, `site/plan-renderers.js`, `site/three-view.js`, and the existing D1 adapters. Branch: `codex/ui-v2-main-wip`. **No browser acceptance was run for this document.** “Dispatch” means a render function is called; it does **not** guarantee a visible pixel difference.

## State owners / render contract

- `site/app.js`: authoritative `model`, Main inspection `roi`, Mask process limiter `maskRoi`, Slice `section`, Section-only `sectionDetailRoi`, `sectionViewport`, `sectionCollapse`, `activeFace`, and independent `planViews.main/mask`. These must remain **separate concepts in one workstation state**, not be coalesced into one ROI.
- `app.js:renderMask/renderMain/renderSection/renderThree` delegate respectively to `planRenderers.renderMask/renderMain/renderSection` and `threeView.render`; `renderSection` also calls `sectionDetailRoiController.sync`.
- `site/controllers/workspace-view-controller.js:createWorkspaceViewController.renderAll` calls `renderMask`, `renderMain`, `renderSection`, `renderThree` (and legend/editor/UI synchronization). `app.js:renderAll` delegates to it. An eventual v2 scheduler may coalesce work but must preserve the observable dependency graph and no-op-free state updates.
- `site/selection-geometry.js:createSelectionGeometry.roiGeometry` converts **Main ROI** into clip geometry; `app.js:initThree` supplies it as `getClipGeometry`. `operationAreaGeometry` separately intersects process area with `maskRoiGeometry`; **Mask ROI does not directly clip 3D inspection**.

## Implementation handoff tests (not yet executed)

1. Keep source model identity/hash and canonical geometry untouched throughout view-only operations; test no `app.js` boot and no legacy DOM under the combined page.
2. Main ROI drag/edit/clear: assert Main overlay and derived 3D clip/region update **after commit** (do not require speculative intermediate 3D drag updates).
3. Slice A–B moves: assert the Section physical reslice follows and that Mask viewport is not rewritten.
4. Section Detail ROI: assert inset follows Section canvas pixels/viewport without becoming a Main ROI/3D clipping ROI.
5. Mask ROI: assert limiter changes and Mask redraw without treating it as an immediate etch/deposition.
6. Test each view's independent Fit/Pan/Zoom and touch path; Section and 3D must have explicit interaction-mode ownership, not simultaneous gesture handlers.
7. Layer visibility/Z Break/face switch + restore: assert render dependency and model invariants; distinguish invoked renderer from pixel differences.
8. Keep pre-existing 0.25 px Main/Slice assertions unchanged; failures are blocking, not baseline-update triggers.
